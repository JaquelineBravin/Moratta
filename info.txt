## Estrutura final do projeto

Projeto/
├── public/
│   └── img/                  # imagens usadas no site (movidas de img/)
├── design-reference/         # Frame 1.png e paleta-de-cores.jpg (não deployado)
├── src/
│   ├── main.jsx
│   ├── App.jsx
│   ├── index.css             # variáveis de cor, @import Google Fonts, reset básico
│   ├── constants.js          # WHATSAPP_NUMBER, WHATSAPP_MESSAGE, getWhatsAppLink(), links de Instagram/e-mail
│   └── components/
│       ├── Header/           # logo + nav (Projetos / Fale Comigo / Orçamento / Para Arquitetos)
│       ├── Hero/             # seção Home (headline + imagem diagonal via clip-path)
│       ├── Prazer/           # bio da Leticia + foto
│       ├── Projetos/         # grid de 4 cards (projetosData.js com os placeholders do Figma)
│       ├── Arquitetura/      # texto + imagem "arquiteturaPensada"
│       └── Footer/           # "Entre em contato" + ícones whatsapp/instagram/e-mail
├── index.html                # lang="pt-BR", title, meta description, favicon (logo.png), <link> Google Fonts
├── package.json / vite.config.js
├── .gitignore                # node_modules, dist, .env
└── README.md                 # como rodar (npm install / npm run dev / npm run build)

Cada componente usa CSS Module próprio (Nome.module.css) — evita dependência extra (Tailwind/styled-components) e mantém o CSS escopado por seção, fácil de comparar 1:1 com o Figma.

Ícones de WhatsApp/Instagram/e-mail (header social row do Figma e footer) serão extraídos diretamente do Figma (SVG reais do design) em vez de uma lib de ícones genérica, para manter fidelidade visual.

## Passos de execução

1. Scaffold: npm create vite@latest . -- --template react --force na pasta atual (só tem imagens hoje, sem conflito de arquivos de projeto).
2. Reorganizar assets: mover img/* (exceto paleta-de-cores.jpg) para public/img/; mover Frame 1.png e img/paleta-de-cores.jpg para design-reference/.
3. Estilos globais: src/index.css com @import das 5 fontes do Google Fonts e variáveis CSS para as 4 cores.
4. src/constants.js: número do WhatsApp, mensagem padrão, getWhatsAppLink(msg), link do Instagram, e-mail.
5. Construir os componentes na ordem do frame Website (Header → Hero → Prazer → Projetos → Arquitetura → Footer), usando o texto extraído do Figma e o mapeamento de imagens acima. Buscar os ícones sociais reais do Figma durante essa etapa.
6. index.html: title, meta description, lang="pt-BR", favicon a partir de logo.png.
7. README.md: instruções de setup/build.
8. Git: git init, git checkout -b main (se necessário), git remote add origin https://github.com/JaquelineBravin/Moratta.git, criar .gitignore, primeiro commit. Antes do git push, vou confirmar com você já que é uma ação que afeta o repositório remoto.
